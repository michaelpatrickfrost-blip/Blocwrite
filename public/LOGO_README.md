# Blocwrite logo assets

- **blocwrite-logo-white.png** — Cream text on black (#000), for dark UIs (studio sidebar, share dark theme). Black matches app dark backgrounds so the logo doesn’t sit in a visible box.
- **blocwrite-logo-black.png** — Dark text for light backgrounds (login, subscribe, admin, news). Should have a transparent background if you want no visible box on “slight” backgrounds.
- **blocwrite-logo-black-bg.png** — Same cream-on-black design as white; used as an alias/backup.

To add a fully transparent logo for light surfaces (no box on slight backgrounds), add **blocwrite-logo-transparent.png** (dark text, transparent background) and we can update references.
